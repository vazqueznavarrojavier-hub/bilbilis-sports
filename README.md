# Bílbilis Sports

Portal deportivo con dos áreas principales:

- **Calatayud**: agenda deportiva local.
- **Internacional**: selección de grandes eventos deportivos.

## Stack

- Vite
- React
- React Router
- Supabase preparado para la siguiente fase

## Desarrollo

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Incluido en el prototipo

- Portada
- Área Calatayud
- Área Internacional
- Filtros por deporte
- Calendario conjunto
- Vista “Este fin de semana”
- Ficha de evento
- Panel Admin básico
- Alta local de eventos mediante localStorage
- Diseño responsive

Los eventos precargados son datos de demostración. La siguiente fase conectará eventos, clubes y recintos con Supabase y fuentes reales.
